# 🩺 Twisted Medicine — Renal System Master MCQ Bank
### بنك mcq تقفيل مديول الرينال (1,806 سؤال تفاعلي)

منصة تعليمية تفاعلية شاملة لأسئلة بنك مديول الرينال (Renal System Module) التابع لسلسلة **Twisted Medicine**. يحتوي البنك على **1,806 سؤال** مقسمين على **43 درساً ومحاضرة (Masterclasses)** تغطي جميع الأقسام الأكاديمية والكلينيكال بترتيب مذكرة المراجعة.

---

## 🌟 مميزات المنصة (Key Features)

1. **🎓 وضع الدراسة التفاعلي (Study Mode):**
   - تصحيح فوري للإجابات (أخضر للإجابة الصحيحة / أحمر للخاطئة مع كشف الإجابة الصحيحة).
   - إظهار نقاط الـ High-Yield والشرح بعد كل إجابة.
   - دعم اختصارات لوحة المفاتيح (`A`, `B`, `C`, `D`, `E` للاختيار، والأسهم للتنقل).

2. **⏱️ وضع الامتحان التجريبي (Timed Exam Mode):**
   - محاكاة لاختبارات البورد والقسم مع مؤقت زمني دقيق.
   - اختيار عدد الأسئلة (10 أسئلة سريعة، 25 سؤال، أو امتحان الدرس بالكامل 42 سؤال).
   - جدول تنقل سريع بين الأسئلة (Question Palette).
   - تقرير درجات تفصيلي وإحصائيات دقة ونسبة مئوية عند انتهاء الامتحان.

3. **⚡ وضع الفلاش كاردز (Flashcards Mode):**
   - بطاقات تفاعلية بوجهين (Active Recall): الوجه الأول يحتوي على نص السؤال والخيارات، وبالنقر يتم قلب البطاقة لإظهار الإجابة الصحيحة والـ High-Yield Matrix.

4. **⭐️ جداول المقارنة ونقاط الـ High-Yield (Note ⭐️ Matrix):**
   - قسم خاص لعرض جداول المقارنة والنقاط المحورية المضافة بعد كل درس لمقارنة المعلومات المهمة للـ MCQ.

5. **🔍 بحث فوري شامل (Global Instant Search):**
   - محرك بحث خفيف وسريع يبحث لحظياً في جميع الـ 1,806 أسئلة عبر الكلمات المفتاحية، الأمراض، الأدوية، والتركيبات التشريحية.
   - اختصار سريع: `Ctrl + K` أو `Cmd + K`.

6. **🔖 حفظ الأسئلة ومراجعة الأخطاء (Bookmarks & Review):**
   - إمكانية تمييز أي سؤال بنجمة (☆ / ★) لحفظه في قائمة المراجعة السريعة.

7. **🌙 الوضع الليلي والنهاري (Dark & Light Themes):**
   - تصميم طبي حديث ومريح للعين مع حفظ الوضع المفضل تلقائياً.

8. **🔊 مؤثرات صوتية تفاعلية (Web Audio Synthesizer):**
   - أصوات تأكيدية خفيفة وممتعة للإجابات الصحيحة والخاطئة مبنية بالكامل على Web Audio API بدون أي ملفات خارجية.

## 🏷️ تصنيف الأسئلة بالبنك (Classification Matrix)

تم ترقيم وتصنيف الأسئلة بنفس النظام الدقيق لملف Twisted Medicine:
- `[2019 – 2025 Exam]`: أسئلة امتحانات السنوات السابقة دور أول وثاني وفورماتيف مع توثيق سنة كل سؤال.
- `[Core Exam] ⭐️`: الأسئلة المحورية التي تغطي حجر الزاوية ولا يخلو منها أي امتحان.
- `[Faculty Exam]`: أسئلة كتاب القسم التي لم ترد في السنوات السابقة.
- `[Clinical Vignette]`: أسئلة الحالات السريرية والسيناريوهات الكلينيكال غير المباشرة.
- `[Practical Mcq]`: الأسئلة المرتبطة بالعملي والجار والسلايدز.
- `(Note ⭐️)`: جداول المقارنة الشاملة الموضوعة بنهاية كل درس.

## 🚀 التشغيل والنشر (Deployment)

المشروع مصمم ليكون **Zero-Dependency Static Web App**:
- لا يحتاج لأي سيرفر خلفي (Backend-less).
- يعمل 100% بدون إنترنت (Offline-capable).
- جاهز للنشر الفوري والمباشر على **GitHub Pages**.

### للتشغيل محلياً:
```bash
cd twisted-medicine-renal
python3 -m http.server 8080
```
